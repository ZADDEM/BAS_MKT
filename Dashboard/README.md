# Analytics Dashboard MKT

Este es un dashboard interactivo estático especialmente diseñado para alojarse gratuitamente en [GitHub Pages](https://pages.github.com/).

## 🚀 Despliegue en GitHub Pages

Debido a que el código fue escrito en HTML, CSS y JS puro consumiendo API externa (Serverless), no necesitas instalar Node.js ni compilar nada.

### Pasos exactos para subirlo:
1. Sube los 3 archivos principales (`index.html`, `app.js`, `styles.css`) a tu nuevo repositorio de GitHub.
2. En GitHub, ve a la pestaña **Settings** (Configuración) de tu repositorio.
3. En el menú lateral izquierdo haz click en **Pages**.
4. Bajo la sección *Branch*, cambia "None" por **main** (o master) y haz click en **Save**.
5. ¡Listo! Espera un minuto y GitHub te dará un link web real y público (Ej: `https://tuusuario.github.io/tu-repo/`) para ver tu dashboard en vivo y desde tu móvil. 

*PD: Recuerda que tu URL secreta de Google Sheets ya quedó guardada directamente dentro de app.js.*
